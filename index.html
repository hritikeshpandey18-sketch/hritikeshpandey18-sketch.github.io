In progressM.Sc. research · Computer vision

AI-Based Coral Reef Health Monitoring Using Underwater Image Processing

Coral bleaching is one of the clearest visual signs of reef decline, yet surveys still rely on trained divers and manual image review. This research asks how well AI can tell healthy coral from bleached coral in underwater photographs.

Data

896 underwater coral photographs labelled healthy or bleached, with duplicate images removed before splitting.

Approach

A four-stage underwater image restoration (Gray-World, CLAHE, bilateral filter, sharpening) feeding ImageNet transfer learning.

Evaluation

Four CNN backbones compared with 5-fold cross-validation and statistical tests; Grad-CAM shows where each model looks.

Goal

A technology-assisted approach that helps researchers monitor coral reef ecosystems more efficiently.

  • Python
  • TensorFlow / Keras
  • OpenCV
  • MobileNetV2
  • ResNet50
  • EfficientNet
  • DenseNet
  • Grad-CAM
